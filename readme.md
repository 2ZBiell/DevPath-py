# 🚀 DevPath

O **DevPath** é uma plataforma desenvolvida para buscar cursos de programação e ferramentas relacionadas à área de desenvolvimento. O projeto foi pensado para **programadores iniciantes e estudantes** que precisam de ajuda para encontrar conteúdos e cursos que contribuam para sua formação e desenvolvimento profissional.

---

## 📌 Sobre o Projeto

O DevPath tem como objetivo facilitar a busca por cursos de programação, reunindo informações sobre diferentes opções de aprendizado em uma única plataforma.

A proposta é oferecer uma experiência mais simples para que o usuário possa **buscar, filtrar, consultar detalhes e acessar os cursos** de seu interesse.

## 🔎 Funcionalidades

Entre as principais funcionalidades planejadas para o DevPath estão:

* Buscar cursos de programação
* Filtrar cursos de acordo com diferentes critérios
* Visualizar informações e detalhes dos cursos
* Favoritar cursos
* Acessar o site oficial dos cursos
* Criar e gerenciar uma conta de usuário
* Armazenar informações utilizando banco de dados

---

## 🛠️ Tecnologias

O projeto está sendo desenvolvido utilizando **Python** e conta com um banco de dados **SQLite** para armazenamento das informações.

Outras tecnologias e bibliotecas serão adicionadas conforme o desenvolvimento das funcionalidades do projeto.

## ▶️ Como Executar

### 1. Clonar o repositório

```bash
git clone https://github.com/2ZBiell/DevPath.git
```

### 2. Acessar a pasta do projeto

```bash
cd DevPath
```

### 3. Criar um ambiente virtual

```bash
python -m venv .venv
```

### 4. Ativar o ambiente virtual

No Windows:

```bash
.venv\Scripts\activate
```

### 5. Instalar as dependências

```bash
pip install -r requirements.txt
```

### 6. Executar o projeto

```bash
python main.py
```
